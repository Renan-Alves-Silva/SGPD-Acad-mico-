# SGPD Acadêmico — Sistema de Gestão de Processos Digitais

---

## Objetivo do Projeto

O **SGPD Acadêmico** tem como objetivo desenvolver uma solução digital capaz de **centralizar, organizar e acompanhar solicitações internas**, reduzindo falhas de comunicação, retrabalho e atrasos operacionais.

### Objetivos específicos

* Mapear processos organizacionais e identificar gargalos;

* Levantar requisitos funcionais e não funcionais;

* Modelar fluxos utilizando BPMN e diagramas UML;

* Desenvolver um protótipo funcional de baixa fidelidade;

* Simular um sistema de acompanhamento de solicitações;

* Aplicar práticas de versionamento e documentação técnica;

* Exercitar metodologias ágeis durante o desenvolvimento do projeto.

## Como Executar o Projeto

### Pré-requisitos

* Python 3.11 ou superior

* Git instalado

### Passos

```
# Clonar o repositório
git clone https://github.com/usuario/sgpd-academico.git

# Acessar a pasta do projeto
cd sgpd-academico

# Instalar dependências
pip install -r requirements.txt

# Executar o sistema
python main.py
```
